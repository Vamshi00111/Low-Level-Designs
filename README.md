# Low-Level Designs

This repository contains various Low-Level Design (LLD) implementations for common system design problems. Each file provides a structured approach to solving real-world design challenges, adhering to software engineering principles such as **SOLID**, **scalability**, and **maintainability**.

## 📂 Repository Structure

| File Name | Description |
|-----------|------------|
| `Amazon_Locker.py` | Design of an Amazon Locker system for secure package deliveries. |
| `Design_Hashmap.py` | Implementation of a custom hashmap with efficient operations. |
| `File_System.py` | A simplified file system supporting basic operations like create, read, and delete. |
| `Job_Scheduling.py` | Implementation of job scheduling algorithms to optimize execution. |
| `Linux_Find.py` | Design of a `find` command for searching files based on conditions. |
| `Parking_Lot.py` | Parking lot management system handling different vehicle types and parking rules. |
| `Pizza_Cost.py` | Cost calculation system for pizzas with various toppings and sizes. |
| `Unix_tail_N_command.py` | Implementation of the Unix `tail -N` command to display the last N lines of a file. |
| `load_balancer.py` | A load balancer design for distributing traffic among multiple servers. |

## 🛠️ Key Features
- **Object-Oriented Design (OOD)** principles applied to ensure modularity and maintainability.
- **Design Patterns** such as Singleton, Factory, and Observer used where applicable.
- **Scalable Architectures** designed to handle growing system demands.
- **Code Readability & Documentation** for better understanding and ease of use.
